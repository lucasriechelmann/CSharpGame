# Feature map

What each functional area does and which folders own it. Individual files are named only for entry points.

## Built

| Area | What it does | Owner | Entry points |
|---|---|---|---|
| Game loop | Window, fixed-timestep simulation with render interpolation (`PreviousTransform`, `RenderClock`), per-frame update, render. Hooks: `Load`, `Update`, `FixedUpdate`, `Draw`, `DebugGui`, `Unload`. | `src/Engine.Runtime`, `src/Engine.Platform`, `src/Engine.Core/FixedTimestep.cs` | `Game`, `GameWindow` |
| Debug UI | Dear ImGui overlay (FPS, fixed steps, alpha, entities, assets, VSync); games add panels via `DebugGui`. F1 toggles. | `src/Engine.Runtime` | `DebugOverlay` |
| ECS | Entities, components, queries, systems, deferred changes. | `src/Engine.Core/Ecs` | `World`, `ISystem`, `SystemGroup`, `CommandBuffer` |
| Input | Keyboard/mouse state with per-frame edges, named actions and axes, ImGui capture respected, focus loss releases all. | `src/Engine.Core/Input`, `src/Engine.Platform` (adapter) | `InputState`, `ActionMap`, `SilkInputAdapter` |
| Assets | Cached, typed, handle-based loading and disposal. | `src/Engine.Core/Assets`, `src/Engine.Rendering` (texture loader) | `AssetManager`, `AssetHandle<T>`, `TextureLoader` |
| Sprite rendering | Batched sprites with tint, pivot, rotation, flip and sprite-sheet regions; 2D camera with zoom/rotation and screen-to-world conversion. | `src/Engine.Rendering` | `SpriteBatch`, `SpriteRenderSystem`, `Camera2D`, `Sprite` |
| Physics and collision | Gravity, terminal velocity, swept AABB-vs-tile and AABB-vs-static-box collision, persistent contact flags. | `src/Engine.Physics2D` | `PhysicsSystem`, `CollisionSolver`, `TileGrid` |
| Platformer controller | Acceleration, jump with coyote time, jump buffering, variable height, heavier fall; tuning editable live. | `src/Engine.Physics2D` | `PlatformerControllerSystem`, `PlatformerTuning` |
| Tilemaps | Sparse chunked tile layers, atlas tile sets with solid flags, camera-culled rendering in background/foreground passes, collision grid derived from a layer. | `src/Engine.Tilemaps` | `TileLayer`, `TileSet`, `TileLayerRenderSystem`, `TileGridBuilder` |
| Sprite animation | Frame clips (loop, once, ping-pong) and a parameter-driven state machine that picks the clip; per-entity playback with speed and finished flag. | `src/Engine.Animation` | `AnimationStateMachine`, `SpriteAnimator`, `AnimationSystem` |
| Scenes and prefabs | Save/load the whole world as JSON, entity templates (prefabs) with merge overrides and inheritance, assets referenced by name, all-or-nothing loading, JSON loaders for tile layers, tile sets and animation graphs. | `src/Engine.Scenes`, `src/Engine.Runtime` (`EngineComponents`, loader registration), loaders in `Tilemaps`/`Animation` | `SceneSerializer`, `ComponentRegistry`, `JsonMerge`, `Game.Scenes` |
| Post-processing | Scene drawn into an off-screen target when any effect is enabled; enabled effects ping-pong between two targets, the last writes to the window. Built-in: colour grade (brightness, contrast, saturation, tint), vignette, bloom (bright pass, half-resolution separable blur, add). All settings editable live in the "Post effects" window. | `src/Engine.Rendering/PostProcessing`, `src/Engine.Runtime` (frame hooks, panel) | `PostProcessChain`, `IPostEffect`, `SinglePassEffect`, `RenderTarget`, `Game.PostProcess` |
| 2D lighting | `Light2D` point lights (colour, intensity, radius, smooth falloff) drawn additively into a screen-sized light map cleared to the ambient colour, then multiplied over the scene; off-screen lights culled. No shadows. | `src/Engine.Rendering/Lighting` | `Light2D`, `LightingEffect`, `LightMath` |
| Entity inspector | Window listing every entity (named by its `Name` component) with filter, create and destroy; the selected entity's components are editable live through reflection (floats, ints, bools, strings, enums, vectors, quaternions as Euler degrees, colours, nested structs), components can be added from the registry and removed. | `src/Engine.Runtime/Inspector`, `World.Reflection.cs` in Core, `ComponentRegistry.Describe` | `EntityInspector`, `FieldEditor` |
| High scores | Best five runs (score, time, won/lost) saved to `saves/highscores.json`, shown on the end screen with the new rank highlighted. | `samples/Platformer` | `HighScores`, `PlatformerGame.Scores.cs` |
| Moving platforms | Solid platforms that slide along a path and carry bodies standing on them (also lift a body that lands on a rising one); one wooden bridge in the sample level. | `src/Engine.Physics2D` | `MovingPlatform`, `MovingPlatformSystem` |
| Pause | `Game.IsPaused` freezes simulation and animation; `Game.Quit()`; the sample opens a Resume / Restart / Quit menu with Esc or P (keys or mouse). | `src/Engine.Runtime`, `samples/Platformer` | `Game.IsPaused`, `PauseMenu` |
| Scene editor (12a, 12b) | F2 freezes the game and opens an editor: dockable windows, hierarchy (filter, new, duplicate, delete), inspector, click-to-select in the scene, move gizmo (axes/free, Ctrl snaps), pan/zoom, Save/Reload scene, undo/redo (Ctrl+Z / Ctrl+Y) for every edit, Play/Stop (F3) that runs the game in the editor and restores the edited world on Stop, tile painting (palette, undoable strokes, layers saved back to their `.layer.json`), prefab-aware saving (instances written as prefab + overrides). | `src/Engine.Runtime/Editor` | `SceneEditor`, `EntityPicking`, `MoveGizmo`, `CommandStack`, `TilePainter` |
| Asset hot-reload | Edited textures, tile layers, tile sets, prefabs, animations and sounds that are loaded reload in place while the game runs (debounced file watcher, retry on locked files, polled on the game thread). | `src/Engine.Core/Assets`, `src/Engine.Runtime` (`Game.HotReloadRoot`) | `AssetHotReloader`, `AssetManager.Reload` |
| Logging | `Logger` with pluggable sinks (console, in-memory ring buffer for the "Log" debug window with a minimum-level selector), levels Debug..Error, categories; `Game.Log` is ready from the constructor. | `src/Engine.Core/Logging`, `src/Engine.Runtime/Inspector/LogPanel.cs` | `Logger`, `ILogSink`, `MemoryLogSink` |
| Profiler | Per-section timing (every system in the three groups plus `Game.Update/FixedUpdate/Draw`, `Debug UI` and `CPU frame`), 120-frame history, last/avg/max table and a frame graph. Games add sections. | `src/Engine.Core/Diagnostics`, `src/Engine.Runtime/Inspector` | `Profiler`, `SystemGroup.Profile`, `ProfilerPanel`, `Game.Profiler` |
| Audio | WAV (8/16-bit, mono/stereo) decoding into `AudioClip` assets, OpenAL playback with a 32-voice pool (oldest voice stolen when full), per-sound volume, pitch and loop, master volume, preload, silent fallback device when none exists. 2D only: no positional audio. | `src/Engine.Audio`, `src/Engine.Runtime` (loader, device lifetime, overlay line) | `IAudioDevice`, `OpenAlAudioDevice`, `AudioClip`, `Game.Audio` |
| Playable game (sample v1) | Collect every coin (25, placed as prefabs on the platforms) to open the exit, reach it to win; creatures hurt (3 lives, 1.5 s invulnerability, respawn at the last checkpoint, 2 s start grace) or die when stomped from above; score = coins + stomps + time bonus; HUD, win/lose screens, Enter restarts; sounds for every event; coins and lamps are `Light2D` lights. Quick-load re-syncs the coin count. | `samples/Platformer` | `GameSession`, `InteractionSystem`, `Coin`, `Goal`, `PlatformerGame.Flow.cs`, `PlatformerGame.Hud.cs` |
| Sample game | Data-driven tilemap level (`Assets/scenes/level.scene.json` plus prefabs, layers, tile set, animations), animated crowned hero you run and jump with, animated patrolling creatures spawned from a prefab, F5/F9 quick-save and quick-load of the whole world, scroll or Q/E to zoom, camera follows hero, live "Hero feel" panel. Pixel art is generated by `tools/make-sprite-sheets.ps1`; the JSON content is hand-editable. | `samples/Platformer` | `PlatformerGame` (partials), `Assets/scenes/level.scene.json`, `Program.cs` |
| 3D rendering (13a-b) | Procedural meshes (cube, plane, sphere) and `MeshRenderer` entities drawn with a depth buffer, back-face culling and frustum culling; materials from `.material.json` (colour, texture, shininess, specular, unlit, double-sided); Blinn-Phong lighting in linear light with ambient, one sun and many point lights (8 per draw, chosen per mesh); `Camera3D` (perspective, `LookAt`, picking ray) and `FlyCamera`; mipmapped, tiling textures. | `src/Engine.Rendering3D`, `src/Engine.Rendering` (depth targets, trilinear), `src/Engine.Runtime` (component and loader registration) | `MeshRenderSystem`, `MeshRenderer`, `Camera3D`, `Material`, `MeshBuilder`, `DirectionalLight`, `PointLight3D` |
| glTF models (13c) | `.gltf` and `.glb` files (positions, normals, UVs, 8/16/32-bit indices, interleaved and normalised data, node hierarchy, base colour factor and texture, roughness, double-sided) load as `Model` assets and draw with `ModelRenderer`; `GltfWriter` exports procedural geometry. No skins, animation, sparse data, Draco or PBR. | `src/Engine.Rendering3D` (`Gltf/`, `Model`), `tools/make-models.cs` | `GltfImporter`, `Model`, `ModelRenderer`, `GltfWriter` |
| 3D physics (13d) | Dynamic boxes fall, slide and come to rest on static boxes (gravity, terminal speed, ground friction, swept per-axis collision, contact flags), plus raycasts against the solids that return the face normal and the entity. No body-vs-body, no rotation, no other shapes. | `src/Engine.Physics3D` | `PhysicsSystem3D`, `CollisionSolver3D`, `BoxCollider3D`, `PhysicsBody3D` |
| 3D sample | A lit room loaded from `room.scene.json` (floor, spinning cubes, spheres, a glTF house, sun, two coloured point lamps) with a fly camera (right mouse look, WASD, Q/E, Shift), Space to throw physics crates and left click to cast a ray (marker at the hit point). | `samples/Scene3D` | `Scene3DGame`, `Assets/scenes/room.scene.json` |
| Transform hierarchy (14) | `Parent` makes an entity a child with a local `Transform`; world matrices come from the parent chain (`TransformHierarchy`), render systems (sprites, lights, meshes) and static solids honour it with interpolation at every level; scenes save `"parent"` indices; the editor Hierarchy is a tree with drag-to-reparent, child creation and subtree delete/duplicate, all undoable; glTF import keeps its node tree (`ModelData.Nodes`, `ModelPose`). Moving physics bodies and tile layers must be roots. | `src/Engine.Core/Hierarchy`, `src/Engine.Runtime/Editor`, `src/Engine.Scenes`, `src/Engine.Rendering3D` | `TransformHierarchy`, `Parent`, `ReparentCommand`, `HierarchyPanel` |
| Visual verification | Scripts to launch, drive and screenshot the sample, and to regenerate its art and sounds. | `tools/` | `tools/README.md` |

## Roadmap

Status of the phased plan (update when a phase lands or the plan changes):

1. Foundation: window, fixed-timestep loop, ImGui debug UI. **Done**
2. Sparse-set ECS with tests. **Done**
3. GL wrapper, shaders, textures, batched sprite renderer, 2D camera. **Done**
4. Input mapping, asset cache, sprite demo. **Done**
5. AABB/tile collision, own simple physics, platformer controller (coyote time, jump buffering). **Done** (spatial hash, one-way platforms, slopes, moving platforms added in phase 11)
6. Tilemaps (chunked, texture atlas) and sprite animation (clips, state machines). **Done** (tile flip flags, animated tiles, parallax, cached chunk meshes and Tiled import deferred)
7. JSON scenes and prefabs (System.Text.Json, components as serializable data, assets saved by name). **Done** (entity references, scene-in-scene, instance-to-prefab links and binary scenes deferred)
8. ImGui entity inspector/profiler, OpenAL audio. **Done** (click-to-select entities in the world, undo/redo, prefab-aware editing, GPU timing, audio streaming for music, positional audio, an audio component and mixer groups deferred)
9. Framebuffers, post-processing, 2D lights. **Done** (light shadows/occluders, normal-mapped lighting, HDR targets, render-to-texture for game code, MSAA, per-camera effects and a pixel-perfect low-resolution mode deferred)
10. Playable platformer v1. **Done** (single level, no enemy variety, no main menu (pause menu added in phase 11); kept deliberately small).
11. Polish and hardening: render interpolation, logging, pause menu, saved high scores, checkpoints, moving platforms. **Done**.
12. Editor: 12a foundation (docking, hierarchy, picking, move gizmo, save/reload), 12b undo/redo, 12c authoring tools (Play/Stop, tile painting, prefab-aware saving, asset hot-reload). **Done** (single-tile brush, move gizmo only, no game-view panel yet; see `tasks.md` for follow-ups). 13. 3D: 13a mesh, material, depth buffer, `Camera3D`; 13b basic lighting; 13c glTF loading; 13d the 3D physics decision (own module, staged) and its first slice. **Done**. See `tasks.md` for what the 3D foundation still lacks. 14. Transform parents and hierarchy: `Parent`, `TransformHierarchy`, hierarchy tree in the editor, scene `parent` links, glTF node tree kept. **Done** (physics bodies stay roots; no cached world matrices yet).

Known gaps to keep in mind: lights do not cast shadows (light passes through walls) and the light map is 8-bit so overlapping lights clamp at white, post effects work on the whole window (no per-camera or per-layer effects) and run at window resolution, audio decodes whole files into memory (no streaming, so long music is costly), no positional audio, sounds are fire-and-forget (no audio component or per-entity voices), the inspector cannot select by clicking in the world and its edits are not undoable, no file log sink, high-DPI untested, tiles are submitted as one quad per visible tile (no cached chunk meshes), bodies spawned inside solids are not pushed out, animation has no events/blending and one transition per update.
